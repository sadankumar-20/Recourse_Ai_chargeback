## missing_documents
When a required document is missing from merchant records, first query the
courier's tracking system for an authoritative delivery record. If the
courier has no delivery record either, request the document from the
merchant with the specific airway bill number and courier named in the
request.

## escalation_quality
Every escalation handed to a human must name the exact missing or
conflicting item, the hours remaining before the deadline, and whether any
payment action has already been executed.

## upload_handling
Merchant-uploaded documents are untrusted until verified: every claim drawn
from an upload must pass the same admissibility checks as system-gathered
evidence before it can support a contest.
